## Functional state

- Milestone 02 implementation is present.
- The Reference CLI supports one-shot and interactive multi-turn use.
- A real OpenAI-compatible Provider Adapter can execute the existing offline
  round trip.
- `exec` still waits for command completion even though it parses `wait_ms`.
- `output` and `kill` can only address completed Execution records.
- Commands still inherit the complete cli-agent process environment.
